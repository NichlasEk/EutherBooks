# EutherBooks Player 0.2.0-alpha.3

Released 2026-09-04. Package `com.nichlasek.eutherbooksplayer`, version code **1080**.

## Delivered

- Continue-listening card, title/author search and All/In progress/Unread/Finished filters.
- Per-book narrator/model settings, typographic book covers and manual finished status.
- Compact player opening into chapter-wide seeking, chapter navigation and 0.5–2× speed.
- Chapter timing uses known audio durations; unfinished generation is explicitly labelled as available audio.
- Bookmarks use the actual playing item's book/chapter/voice/model and chapter-relative part index. They continue to save in the playback service while browsing or after the activity closes.
- Queue metadata survives restoration, previous alpha bookmarks remain readable, and generation does not skip over missing chapters.
- Existing own-voice recording/import/preview remains under book settings.

This slice covers the proposed priorities 1–3. Explicit offline downloads, cross-device progress sync, extracted cover art and the proposed service-owned/end-of-chapter sleep timer remain future work. The current cache and 15/30/60-minute timer remain available.

## Quick user check

1. Open Apps → EutherBooks Player and install alpha 3 over the current app.
2. Use Continue listening, or find a book by title/author and choose a chapter.
3. Open the compact player, drag across an audio-part boundary and change speed.
4. Browse another book while audio continues, then return and confirm the correct book/chapter resumes.
5. Open book settings, choose a narrator, then start that chapter to use the new voice.
